# LCARS Framework: Користувацька документація та технічний довідник

## 1. Огляд системи
**LCARS Framework** — це модульна, подійно-орієнтована інженерна підкладка, розроблена для керування складними симуляціями Geant4 та реконструкції інтерфейсів. Система працює за принципом "ізолінійної матриці", де спеціалізовані масиви штучного інтелекту керують різними аспектами архітектури та візуалізації.

---

## 2. Інженерна станція (Workbench)
Інженерна станція — це центральний вузол для всіх завдань з розробки та аналізу. Вона розділена на три основні функціональні рівні:

### ◤ ISOLINEAR ARCHITECT (IDE високого рівня)
Професійне середовище для автоматизованої реконструкції UI та аналізу архітектурних креслень.
*   **Нейронна реконструкція**: Використовує `UIAnalyzer` для виявлення патернів та відтворення макетів інтерфейсу зі скріншотів або схем.
*   **Калібрування сітки**: Надає нейронну сітку 50px для точного структурного вирівнювання.
*   **Накладення схем (Blueprints)**: Підтримує завантаження зображень-схем як еталонних шарів.

### ◤ INTERFACE CONSTRUCTOR (Низькорівневий асемблер)
Внутрішня програма, спеціалізована для ручного збирання компонентів UI з примітивних фігур.
*   **Розгортання примітивів**: Швидке розміщення Г-подібних елементів (Elbows), структурних панелей, текстових блоків даних та командних кнопок.
*   **Ізолінійна синхронізація**: Використовує унідифіковану логіку `EditMode` для перетягування, зміни розміру та точного позиціонування елементів.
*   **Зв'язування даних**: Дозволяє призначати ID та текст міток для примітивів для подальшого експорту.

### ◤ COMPUTER CORE (Центр інтелекту)
Інтерактивний інтерфейс для зв'язку зі спеціалізованими масивами ШІ системи.
*   **MAJEL CORE**: Центральний вузол інтелекту. Керує загальними операціями системи.
*   **M-5 MULTITRONIC**: Спеціалізується на структурній логіці та архітектурній цілісності.
*   **ZORA BIOTIC**: Спеціалізується на візуальному синтезі та реконструкції патернів UI.

## 3. Нейронна консоль та термінал
Термінал слугує мостом між логікою LCARS та фізичною операційною системою.

### Режими виконання команд:
1.  **Режим LCARS CORE**: Пряма взаємодія з логікою `BoardComputer`.
2.  **Режим SYSTEM OS**: Прямий доступ до оболонки хост-машини (PowerShell/Bash).

### Основні системні команди (режим LCARS):
| Команда | Параметр | Функція |
| :--- | :--- | :--- |
| `status` | - | Відображає внутрішній стан системи, час роботи та завантажені плагіни. |
| `metrics` | - | Показує телеметрію CPU, пам'яті та диска в реальному часі. |
| `projects` | - | Перелічує всі виявлені проєкти Geant4 у робочому просторі. |
| `analyze` | `[назва_проєкту]`| Глибоке сканування вказаного проєкту (кількість файлів, розмір, статус Geant4). |
| `health` | - | Запускає самодіагностику нейронної підкладки. |
| `alerts` | - | Список активних сповіщень та попереджень системи. |
| `terminate`| - | Безпечне завершення інтерактивної сесії LCARS. |

## 4. Логіка UI та EditMode
**EditMode Substrate** — це базовий рушій, який дозволяє маніпулювати всіма елементами UI на інженерній станції в реальному часі.

### Керування маніпуляціями:
*   **Вибір**: Натисніть на елемент, щоб активувати його нейронний зв'язок.
*   **Переміщення**: Натисніть та тягніть будь-який вибраний примітив.
*   **Візуальний відгук**: Елементи підсвічуються помаранчевим кольором (`#FF9900`), коли вони активні.

---

## 5. Протоколи масивів інтелекту
Кожен агент ШІ призначений для специфічної інженерної ролі:

*   **MAJEL**: Використовуйте для запитань про системні файли, реєстр плагінів та загальної допомоги.
*   **M-5**: Використовуйте при проектуванні складних структурних макетів або аналізі архітектури проєктів.
*   **ZORA**: Використовуйте для завдань, що стосуються колірних палітр, естетики UI та візуальної реконструкції.

---

## 6. Логіка виявлення проєктів
`ProjectManager` автоматично сканує батьківську директорію на наявність папок, що відповідають наступним протоколам:
*   `ENX*` (проєкти класу Enterprise)
*   `NCC-*` (стандартні проєкти Зоряного Флоту)

Після виявлення проєкти можна аналізувати через **Консоль** або переглядати у **Project Explorer**.

---

## 7. Кастомізація для розробників
### Підтримка ер та фракцій:
Система підтримує кілька ер (22-29 століття) та фракцій (Федерація, Клінгони, Ромулани, Кардасіани).
*   **Динамічний рушій тем**: Автоматично перераховує колірні палітри та форми кнопок залежно від контексту поточної сесії.
*   **Стани тривоги**:
    *   **GREEN (Зелений)**: Номінальна робота.
    *   **YELLOW (Жовтий)**: Застереження. Візуальний акцент на телеметрії.
    *   **RED (Червоний)**: Критичний стан. Спрощений UI з високою контрастністю та естетикою червоної тривоги.
