# Правила написання коду LCARS Framework

## ЗАБОРОНЕНО - СТРОГО
- **НЕ використовувати Q і Qt напряму**
- **НЕ використовувати "windows" або "main"** - у LCARS таких слів немає!
- **НЕ використовувати "ос"** - Уникати прямих посилань на ОС
- **Нижні підкреслення** - НЕ використовувати `_varname` для приватних змінних, робити довгі слова
- **Трилапки (docstrings)** - НЕ використовувати `"""..."""`
- **ЕКСЕПТИ (exceptions) ЗАБОРОНЕНО!** - Ніяких try/except!
- **Прямі посилання на платформи** - використовувати замінники з реєстру

## Обов'язково

- **Загальний опис файлу** на початку кожного файлу - що робить файл, призначення
- **Детальні пояснення коду** - коментарі зрозумілою мовою (українською/англійською)
- **Коментарі до логіки** - пояснювати ЧОМУ, не лише ЩО
- **Використовувати замінники** - через реєстр (LCARS, registry)
- **Структура коду** - не ламати існуючу архітектуру
- **Компіляція** - всі зміни мають компілюватися без помилок

# LCARS Framework — Огляд проекту

## Версія та статус
- Версія: 1.0.0
- Статус: активна розробка (інтеграція UI/плагінів, виправлення коду)
- Останнє оновлення: 24 лютого 2026

## Останні зміни
- Вбудовано `SystemControlCenter` у головний десктоп (без окремих вікон).
- Реалізовано BIOS-кнопку та ізолінеарний стан з персистентністю.
- Додано динаміку палітри кольорів (таймер + клік для миттєвої зміни).
- Вимкнено автоматичний prestart maintenance за замовчуванням у dev, додано опцію `LCARS_ENABLE_MAINTENANCE`.
- Додано просту систему бортового журналу (`lcars/system/journal.py`) і інтегровано її у старт.
- Перекладено частину документації й інтерфейсних коментарів українською.

## Що зроблено (компактно)
- Інтеграція системних панелей у єдине повноекранне середовище.
- Поліпшено обробку кольорів і взаємодію кнопок.
- Прибрано широкі `except` у ключових точках (початковий крок).
- Додано механізм ведення бортового журналу замість розлогих логів.

## Що ще потрібно зробити
- Повний рефакторинг: видалити або замінити решту широких `except` по репозиторію.
- Замінити `setFixed*` виклики на layout/policies у UI.
- Провести повний QA і написати автоматизовані тести для UI-інтеграцій.
- Завершити переклад документації українською (вміст `docs/`).
- Підготувати реліз: коміт/PR, CI перевірки, оформлення релізних артефактів.

## Структура репозиторію
```
lcars/           # Ядро, UI, теми, плагіни
plugins/         # Плагіни: кожен у власній папці з plugin.yaml
config/          # Налаштування (config.json)
docs/            # Документація розробника і архітектури
tests/           # Тести (unittest)
logs/            # Різні логи (оперативні)
journal/         # Бортовий журнал (щоденні MD файли)
start_lcars.py   # Головна точка входу
start_lcars.bat  # Windows-ярлик/скрипт для запуску
README.md        # Цей файл
```

## Швидкий старт
1. Встановіть Python 3.9+ та створіть віртуальне оточення (рекомендовано).
2. Встановіть залежності:
```bash
pip install -r requirements.txt
```
3. Запуск:
- Windows (GUI): `start_lcars.bat`
- За допомогою Python: `python start_lcars.py`

Швидкий режим: `python start_lcars.py --default`

Автозапуск Windows: `start_lcars.bat --setup-startup` створює ярлик у папці автозавантаження.

## Примітки по поведінці
- За замовчуванням у dev режимі prestart maintenance відключено, щоб не блокувати старт.
- Бортовий журнал зберігає ключові події у `journal/YYYY-MM-DD.md`.
