# lcars/ui/views

Папка `views` містить конкретні UI‑view класи (діалоги, вікна), які є
представленням (presentation) у архітектурі проекту. Коротко:

- `start_menu_view.py` — діалог стартового меню (перший приклад).  
- `project_explorer_view.py` — простий переглядач списку проектів (заглушка).

Стандарт:
- Файли мають українські короткі пояснення на початку.  
- View використовують палітру з `lcars.themes.lcars_palette` та зареєстровані шрифти.
