## LCARS UI — структура

Ця папка містить UI-компоненти LCARS. Правила:

- `desktop.py` — головний shell / DesktopShell
- `start_menu.py` — стартове меню
- `file_manager.py` — файловий менеджер (плейсхолдер)
- `widgets/` — повторно використовувані віджети

UKR: Підтримуємо просту структуру: кожен значимий view має свій файл.
