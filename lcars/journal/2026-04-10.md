## Частина 1: Kernel ONLINE

Ядро системи LCARS повністю побудоване та запущене.
Один синглтон `Kernel` — це і є операційна система.

```
Kernel (singleton)
 ├── Events     : EventBus         — потоко-безпечна шина подій (wildcard "*")
 ├── State      : Store            — реактивний стан (генерує store.changed)
 ├── Services   : ServiceRegistry  — lifecycle з розв'язанням залежностей
 ├── Processes  : ProcessTable     — запущені програми з PID
 └── Phase      : SystemState      — OFF → BOOTING → RUNNING → OFF
```

Тести: 13/13 пройдено (EventBus, Store, Service, Application, Bootstrap).

## Частина 4: Стан системи

### Що працює ✓
- `start_lcars.py` → `bootstrap.Start()` → Kernel RUNNING
- 3 сервіси: config (5 файлів), alert (GREEN/YELLOW/RED), plugins
- Повний lifecycle: Boot → RUNNING → Shutdown → OFF
- 13/13 тестів пройдено
- EventBus, Store, ServiceRegistry, ProcessTable — все операційне

### Що потребує уваги (не критично)
- `lcars/core/nexus.py` та `event_bus.py` — legacy шини подій, використовуються ~15 файлами. Потрібна поступова міграція на `kernel.EventBus`.
- `lcars/system/board_computer.py` — імпортує з nexus, потрібна обгортка як Service.
- `lcars/ui/desktop.py` (`LCARSDesktop`) — головний desktop, імпортується 14 файлами. Потрібна інтеграція з `Kernel.Launch()`.
- `plugins/__init__.py` — посилається на неіснуючий `HostSystem` з `lcars.base.types`. PluginService перехоплює помилку gracefully.

### Ресурси (1751 файл)
Зображення (.png 681, .jpg 428, .gif 364), звуки (.wav 100, .mp3 49), шрифти (.TTF 23), відео (.mp4 17) — по 6 ерах (22nd, 23rd, 24th, 25th + sounds, fonts, animation). Це не код — це ассети UI.
