# LCARSToolkit (C#/WPF) — Archived UI Prototype

This folder contains a C#/WPF prototype of LCARS UI (XAML, code-behind).
It is a visual reference and a standalone .NET prototype, not part of the
main Python runtime. It was moved to `archive/` to keep the Python project
focused while preserving the visual assets and reference controls.

Suggested use:
- Inspect XAML layouts and controls as a reference when porting UI to PyQt.
- Extract colors, fonts and icons into `lcars/themes` and `resources/`.
