## 🎯 **Як використовувати нові модулі:**

### **Метод 1: Через запускник**
```bash
start.bat → [2] Modules Demo (GUI)
```

### **Метод 2: В коді**
```python
import lcars as lcars

# Створити системний монітор
monitor = lcars.start_system_monitor()
monitor.show()

# Створити файловий менеджер
fm = lcars.start_file_manager()
fm.show()

# Створити термінал
term = lcars.start_terminal()
term.show()
```

### **Метод 3: Через фреймворк**
```python
framework = lcars.create_framework()
monitor = framework.create_system_monitor()
fm = framework.create_file_manager()
term = framework.create_terminal()
```
