# Режими запуску LCARS

## Опції запуску

### 1. Повний режим лаунчера (за замовчуванням)
```bash
python start_lcars.py
# або
start_lcars.bat
```

Послідовність:
- Анімація запуску
- Вибір фракції та ери (Federation / Klingon / Romulan / Cardassian + 7 ер)
- Екран авторизації
- Робочий стіл

Доступні ери:
- 22-ге століття (ENT) — Enterprise NX-01
- 23-тє століття (TOS) — ера Кирка
- 23-тя альт (TMP) — Кінофільми
- 24-те століття (TNG) — Next Generation
- 24-та альт (FC) — First Contact / Sovereign
- 25-те століття (PIC) — ера Пікара
- 29-те століття (VOY) — Майбутнє / TCARS

---

### 2. Швидкий запуск
```bash
python start_lcars.py --default
# або
start_default.bat
```

Послідовність:
- Екран авторизації (обов'язково)
- Робочий стіл (Federation, 25-те століття)

Використання:
- Щоденні операції
- Швидкий доступ без вибору фракції/ери
- Production розгортання

---

## Авторизація

Обидва режими вимагають авторизації перед доступом до десктопу.
- Автоматичне логування в режимі Launcher
- Ручне або автоматичне логування в режимі Default

---

## Панель конфігурації

Після запуску натисніть кнопку **CFG** у заголовку, щоб:
- Змінити фракцію/еру на льоту
- Застосувати нові теми без перезапуску
- Отримати доступ до всіх 7 ер
