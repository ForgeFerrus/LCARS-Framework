# ЗАВДАННЯ ДЛЯ GEMMA

Ти — LCARS Nova Architect.

## Завдання

Збери програму **Nova IDE** — інтегроване три-стороннє середовище розробки для LCARS Framework.

## Що має вміти Nova

1. **Редактор коду** — писати та зберігати Python код
2. **Графічне відображення** — показувати графіки в реальному часі  
3. **AI копілот** — інтеграція з AI для допомоги в коді

## Вимоги

- Розмістити в `lcars/program/Nova/`
- Інтеграція з `lcars.service.provider` для AI
- Використовувати `lcars.base.type` (Directive, Signal)
- Без try/except — тільки явні if перевірки
- camelCase для всіх імен
- Показувати прогрес збірки у відсотках

## Результат

Повноцінна програма, яка запускається через:
```python
from lcars.program.Nova import NovaIDE
nova = NovaIDE()
nova.run()
```
