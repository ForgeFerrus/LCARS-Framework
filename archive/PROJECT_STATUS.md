## 🚀 **Як запустити ПРЯМО ЗАРАЗ**

### Метод 1 - Простий запуск (рекомендовано)
```powershell
start_lcars.bat
```

### Метод 2 - Через Python
```powershell
python start_lcars.py
```

### Метод 3 - Діагностика перед запуском
```powershell
health_check.bat
```

### Метод 4 - Альтернативні лаунчери
```powershell
python launcher.py
python launcher_modern.py
python launcher_minimal.py
```

## 🔧 **Технічна інформація**

### Встановлені пакети
- ✅ PyQt6 (GUI фреймворк)
- ✅ NumPy, Pandas (обробка даних)
- ✅ Matplotlib (графіки)
- ✅ VisPy, PyOpenGL (3D візуалізація)
- ✅ Все необхідне для роботи

### Архітектура
```
lcars/
├── core/     - Ядро функціональності (13 модулів)
│   ├── analysis.py, project_manager.py
│   ├── blender_connector.py, visualizer_3d.py
│   ├── plugin_system.py, event_bus.py
│   └── task_executor.py, environment.py, ...
├── ui/       - Інтерфейси (40+ компонентів)
│   ├── LCARS_22nd-25th.py, TCARS_29th.py
│   ├── Romulan_interface.py, Klingon_system.py
│   ├── widgets.py, detector_designer.py
│   └── network_hub.py, starship_node.py, ...
├── utils/    - Утиліти та теми
└── themes/   - Визначення тем
```

### Логування
- 📝 Файл: `logs/lcars_framework.log`
- 🔄 Ротація: 10MB, 5 файлів
- 📊 Рівні: DEBUG, INFO, WARNING, ERROR
